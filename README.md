Nairobi Air Quality Analysis (PM2.5)

This repository presents a spatial and temporal analysis of particulate matter air pollution in Nairobi using sensor-based air quality data. The project focuses on understanding where pollution is concentrated and how pollution levels change over time.
The analysis uses PM2.5 measurements (represented as P2 in the dataset), which are widely recognized as having significant health impacts.

Objectives

Prepare and clean raw air quality sensor data

Generate representative PM2.5 values for spatial analysis

Map PM2.5 pollution distribution across Nairobi

Identify potential pollution hotspots

Analyze temporal trends in PM2.5 pollution

Examine daily and hourly pollution patterns
